# 英国道路碰撞严重程度预测

[English](README.md) | **简体中文**

## 项目概述

本项目分析英国交通部 2021—2025 年的 513,801 条道路碰撞记录，并预测已报告碰撞是否造成死亡或重伤。分析重点包括碰撞严重程度与时间、照明、限速、城乡环境、道路条件及空间位置之间的关系。

## 研究问题

1. 碰撞数量和 KSI 占比如何随时间及道路环境变化？
2. 碰撞发生时已知的哪些信息最能区分 KSI 与轻伤碰撞？
3. 入选模型在独立的未来年份上表现如何？
4. 哪些特征对模型的预测排序贡献最大？

## 目标与数据

KSI 指 **Killed or Seriously Injured（死亡或重伤）**。死亡和重伤碰撞编码为 `KSI=1`，轻伤碰撞编码为 `KSI=0`。

数据覆盖 2021—2025 年已报告的人员伤亡道路碰撞，来源为英国政府发布的 [Road safety open data](https://www.gov.uk/government/statistical-data-sets/road-safety-open-data)。

为减少目标泄漏，并避免使用碰撞发生时尚不可得的信息，模型排除了伤情结果衍生字段、碰撞标识符、精确位置标识符、伤亡人数和警员是否到场等字段。

## 分析设计

分析分为三个阶段：

1. 验证原始数据字段，处理重复记录，统一字段并形成碰撞级数据集。
2. 使用数量、比例和 95% Wilson 置信区间描述严重程度构成，以及时间、环境、道路和空间模式。
3. 采用时间外评估，对比多数类基线、类别加权逻辑回归和调参后的 LightGBM。

LightGBM 调参使用 2021—2023 年内的扩展年度窗口。最终比较使用 2021—2023 年训练，在 2024 年选择模型和分类阈值，并在独立的 2025 年测试集上进行一次评估。

## 主要描述性结果

- KSI 占已报告碰撞的 24.2%，轻伤碰撞占 75.8%。
- 年度碰撞数量相对稳定，但基于伤情的严重程度记录方式占比显著上升。
- 碰撞数量在下午达到峰值，而记录的 KSI 占比在午夜前后最高。
- 无道路照明的黑暗环境对应的 KSI 占比明显高于日间。
- 限速与城乡环境存在明显交互；展示的各限速组中，农村道路的 KSI 占比均高于城市道路。
- 碰撞密度热点与高严重程度热点并不稳定重合。

## 模型结果

调参后的 LightGBM 在独立 2025 年测试集（101,525 条记录）上的结果如下：

| 指标 | 结果 |
| --- | ---: |
| ROC-AUC | 0.6396 |
| Average Precision | 0.3819 |
| Brier score | 0.2348 |
| Balanced accuracy | 0.5932 |
| KSI precision | 0.3240 |
| KSI recall | 0.7236 |
| KSI F1 | 0.4476 |
| 验证集确定的阈值 | 0.45 |

在该阈值下，模型识别出 19,280 条 KSI 碰撞，漏掉 7,364 条。在 59,505 条 KSI 预测中，40,225 条为误报，因此模型的召回能力强于精确识别能力。

排列重要性显示，涉及车辆数量被打乱后造成的 Average Precision 降幅最大，其后依次为限速、经度和道路类型。这些数值反映特征在当前模型中的预测贡献，不代表因果影响。

## 解读边界

数据只包含已报告碰撞，没有交通暴露量。因此，KSI 占比描述的是已记录碰撞中的严重程度，而不是每次出行、每公里或每位道路使用者的碰撞风险。跨年度变化还可能受到严重程度记录方式变化的影响。描述性差异和模型重要性均应理解为关联，而非因果关系。
